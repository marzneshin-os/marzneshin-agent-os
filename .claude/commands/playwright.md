**PLAYWRIGHT BROWSER AUTOMATION (MCP)**

Execute browser automation and end-to-end UI verification:
1. **Navigate**: Open web consoles, dashboards, or target pages.
2. **Interact**: Click buttons, fill forms, and trigger DOM events.
3. **Screenshot**: Capture visual verification snapshots for dashboards.
4. **Inspect**: Evaluate frontend rendering, console errors, and network traffic.
