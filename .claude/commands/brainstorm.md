**SUPERPOWERS PHASE 1: BRAINSTORMING**

Before writing any code or architecture documents:
1. **Explore User Intent**: Clarify what problem is being solved and why now.
2. **Surface Tradeoffs**: Contrast at least two alternative architectures or implementation approaches.
3. **Karpathy Discipline**:
   - Ask: "What is the simplest possible solution that solves this?"
   - Challenge speculative complexity, unneeded abstractions, or preemptive optimizations.
4. **Define Verifiable Boundaries**:
   - Explicitly list in-scope vs out-of-scope files and capabilities.
   - Map against project invariants in `BUILD-SPEC.md` (§1.3 I1-I17).
5. **Human Alignment Checkpoint**: Present options and confirm direction with the user before drafting code.
