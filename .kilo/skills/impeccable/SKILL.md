# Impeccable — Frontend Design Taste & Anti-Slop Director

Eliminate II slop. Build interfaces that look like an exceptional human designer created them.

## Quick Start

Invoke `/impeccable` commands to guide UI design:
- `/impeccable init`: Interview user on product identity, generate `PRODUCT.md` and `DESIGN.md`.
- `/impeccable craft`: Shape-then-build visual hierarchy, intentional palettes, and typography.
- `/impeccable critique`: Review layout, contrast, whitespace, visual weight, and typography.
- `/impeccable polish`: Add micro-interactions, hover/focus states, and skeleton loaders.
- `/impeccable animate`: Meaningful motion design with easing curves and `prefers-reduced-motion`.
- `/impeccable typeset`: Font pairing, modular scale, line length (45-75ch), and responsive type.
- `/impeccable audit`: Scan frontend codebase for banned II slop patterns.

## Core Principles

1. **Anti-Slop:** Ban default Inter-everywhere, generic purple-blue gradients, nested cards, and low-contrast gray text.
2. **Intentional Palette:** Use HSL color spaces with defined semantic tokens and dark mode pairs.
3. **Structured Typography:** Pair max 2 typefaces with a modular scale ratio.
4. **Spacing Harmony:** Rely on a 4px/8px rhythmic spacing scale.
